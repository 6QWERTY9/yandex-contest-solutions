# 📈 yandex-38-room-area Площадь комнаты 

## 📝 Условие задачи

Требуется вычислить площадь комнаты в квадратном лабиринте.

---
## 🎯 Суть алгоритма

1. **Концепция:** Задачу будем решать с помощью **поиска в глубину (DFS)**
2. **Защита:** Чтобы не считать одну и туже клетку мы заведем массив `visited`размером N x N - (это обычная практика для DFS)
3. **Переменная площади:** по условию задачи нам надо вывести площадь лабиринта (количество пустых клеток), для этого мы заведем переменную `roomArea`
4. **Счетчик площади:** Запускаем нашу функцию `dfs(r, c)`, от стартовых координат (при этом вычетая 1 из координат ввода, для перехода по индексам)
   * Если координаты вышли за границы, или в клетке стена `*`, или клетка уже была посещена - выходим с помощью `return`
   * Если клетка еще не была нами посещена, отмечаем ее в `visited` и увеличеваем глобальный счетчик `roomArea++` и рекурсивнно идем по соседям
5. **Финал:** Выводи в консоль `roomArea`

---

## 📥 Формат ввода
* **В первой строке вводится:**  размер лабиринта (3 ≤ N ≤ 10)
* **В следующих N строках задан:** лабиринт **(‘.’ – пустая клетка, ‘*’ – стенка)**.
* **последняя строка содержит:** **два числа – номер строки и столбца клетки**, находящейся в комнате, площадь которой необходимо вычислить. **Гарантируется, что эта клетка пустая и что лабиринт окружен стенками со всех сторон.**
## 📤 Формат вывода
Требуется вывести единственное число – количество пустых клеток в данной комнате.
---

## 💡 Пример
**Входные данные:**
```text
3
***
*.*
***
2 2
```

**Выходные данные:**
```text
1
```
