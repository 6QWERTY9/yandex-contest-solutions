# 📈 yandex-647-broken-ring Разорванное кольцо

## 📝 Условие задачи

**Дан ориентированный граф из n вершин**, заданный массивом a из n целых чисел:

   * Для каждого i (1 ≤ i ≤ n)  есть ребро из вершины i в вершину a<sub>i</sub>
   * Массив a является **перестановкой**.

Ваша задача за **минимальную стоимость** изменить перестановку a таким образом, чтобы весь граф представлял собой **ориентированный граф-цикл**.

Также дан массив b из n целых чисел.

Пусть исходный массив a после всех изменений равен массиву t, тогда стоимость равна $\sum(b_i \cdot [a_i \neq t_i])$
то есть сумме всех $b_i$ для которых верно $a_i \neq t_i$ ($a_i$ не равно $t_i$)
