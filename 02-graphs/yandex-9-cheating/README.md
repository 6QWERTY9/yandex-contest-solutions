# 📈 yandex-9-cheating Списывание

## 📝 Условие задачи
Во время контрольной работы профессор Флойд заметил, что некоторые студенты обмениваются записками. 
Сначала он хотел поставить им всем двойки, но в тот день профессор был добрым, а потому решил **разделить студентов на две группы**:** списывающих** и **дающих списывать**, и поставить двойки только первым.

У профессора записаны все пары студентов, обменявшихся записками. 
**Требуется определить, сможет ли он разделить студентов на две группы так, чтобы любой обмен записками осуществлялся от студента одной группы студенту другой группы.**
---
## 🎯 Суть алгоритма
1. **Главное правило:** 
    * **Если в графе вообще нет циклов (дерево) или есть только четные циклы - YES**.
    * **Если в графе есть хотя бы один нечетный цикл - NO**

2. **Концепция:** двудольность графа - проверяем можно ли раскрасить граф в два цвета так что бы у любых двух соедененных студентов цвета различались иначе ответ будет NO

3. **DFS:**
    * Вместо массива (`visited`) заводи массив (`Colors`) заполниный нулями (0 - не покрашен, 1 - первая группа, 2 - вторая группа)
    * Проверка циклов:
        * Если DFS пытается покрасить соседа а он уже закрашен в текущий цвет то выходим из нашей функции и выводим NO
        * Если мы обошли весь граф то выводим YES

---

## 📥 Формат ввода
- **В первой строке:** находятся два числа **N - количество студентов и M - количество пар студентов, обменивающихся записками** (1 ≤ N ≤ 10<sup>2</sup>, 0 ≤ M ≤ N (N - 1) / 2)
- **Далее в M строках:** расположены описания **пар студентов: два числа, соответствующие номерам студентов, обменивающихся записками** (**нумерация студентов идёт с 1**). 
**Каждая пара студентов перечислена не более одного раза.**

## 📤 Формат вывода
Необходимо вывести ответ на задачу профессора Флойда. **Если возможно разделить студентов на две группы - выведите YES; иначе выведите NO.**
---

## 💡 Пример
**Входные данные:**
```text
3 2
1 2
2 3
```

**Выходные данные:**
```text
YES
```

**Входные данные:**
```text
3 3
1 2
2 3
1 3
```

**Выходные данные:**
```text
NO
```
