# ♞ yandex-knight. Ход конём

## 📝 Условие задачи
Дана прямоугольная доска размером N × M (N строк и M столбцов). В левом верхнем углу находится шахматный конь, которого необходимо переместить в правый нижний угол доски. 

В данной задаче конь может перемещаться только в двух направлениях:
1. **На две клетки вниз и одну клетку вправо** `(i + 2, j + 1)`
2. **На одну клетку вниз и две клетки вправо** `(i + 1, j + 2)`

Необходимо определить, сколько существует различных маршрутов, ведущих из левого верхнего в правый нижний угол. Путь нулевой длины (оставаться на месте на доске 1х1) также считается корректным маршрутом.

---

## 🎯 Суть алгоритма
Задача решена методом **прямого динамического программирования (распространение вариантов вперёд)**.
1. Создаётся матрица памяти `dp` размера N × M, изначально заполненная нулями.
2. **Базовый случай:** в самую первую ячейку старта `dp[0][0]` принудительно записывается `1` (существует ровно 1 способ находиться на старте).
3. **Обход и логика:** алгоритм перебирает ячейки таблицы построчно, слева направо. Если в текущей клетке `dp[i][j] > 0`, это значит, что конь смог сюда доскакать. Из этой точки он делает два своих законных прыжка вперёд и «делится» своими способами со следующими клетками:
   * `dp[i + 1][j + 2] += dp[i][j]`
   * `dp[i + 2][j + 1] += dp[i][j]`
4. **Безопасность:** перед каждым прибавлением выполняется строгая проверка границ, чтобы новые индексы не вылетели за пределы размеров доски (`< N` и `< M`).

---

## 📥 Формат ввода
* Единственная строка содержит два натуральных числа N и M (1 ≤ N, M ≤ 50) — размеры доски.

## 📤 Формат вывода
* Единственное число — количество способов добраться конём до правого нижнего угла доски.

---

## 💡 Пример
**Входные данные:**
```text
3 3
```

**Выходные данные:**
```text
2
```
