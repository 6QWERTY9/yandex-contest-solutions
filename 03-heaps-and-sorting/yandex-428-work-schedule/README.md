# 📈 yandex-428-work-schedule График работ

## 📝 Условие задачи

**Пете на работе выдали n задач.**

**Каждый день, начиная с первого, Петя может выполнить ровно одну задачу.**

Про каждую задачу известен **последний день d<sub>i</sub>**, когда её можно выполнить, **и величина стресса w<sub>i</sub>.**


---

## 📝 Разбор условие задачи


---
## 🎯 Суть алгоритма

1. **Сортировка:**
    Сортируем все задачи по возврастанию дедлайна d<sub>i</sub>

2. **Наполнение:** 
    По очереди берем каждую задачу и вставляем ее уровень стресса в минимальную кучу 

3. **Проверка:**
    Если размер кучи становится больше, чем дедлайн текущей задачи. 
    В этот момент мы извлекаем из кучи элемент с самым низким уровнем стресса. 
    Этой задачой мы жертвуем (извлекаем ее из нашей кучи).

4. **Расчет:**
    После прохода по всем задачам в кучи будут только те что уже выполнены.
    Мы вычитаем из общей суммы стресса всех исходных задач сумму стресса выполненных задач. 
    Результат выводим на экран.


---

## 📥 Формат ввода

*  **В первой строке:** записано число N (1 ≤ N ≤ 200 000)
* **Затем следует n строк:** в каждой из которых содержится по два числа d<sub>i<sub> и w<sub>i</sub> (1 ≤ d<sub>i<sub> ≤ 200 000, 1 ≤ w<sub>i</sub> ≤ 200 000)

## 📤 Формат вывода

**Выведите единственное число, равное минимальному возможному суммарному стрессу.**

---

## 💡 Пример
**Входные данные:**
```text
3
1 2
1 3
3 1
```

**Выходные данные:**
```text
2
```
