# 📈 yandex-251-heapify. Хипуй

## 📝 Условие задачи
Необходимо самостоятельно (не используя встроенные библиотеки) реализовать структуру данных Heap (Двоичная куча) для хранения целых чисел, поддерживающую две операции:
1. **Insert(k)** — добавить число `k` в кучу (ввод начинается с `0 <число>`).
2. **Extract** — извлечь из кучи наибольшее число, удалив его (ввод равен `1`).

Гарантируется, что при вызове Extract в куче есть хотя бы один элемент.

---

## 🎯 Суть алгоритма
Задача идеально решается через структуру **Max-Heap**, реализованную на базе обычного одномерного массива.
1. **Хранение в массиве:** Для узла с индексом `i`:
   * Левый ребёнок: `i * 2 + 1`
   * Правый ребёнок: `i * 2 + 2`
   * Родитель: `Math.floor((i - 1) / 2)`
2. **Insert (Добавление):** Новое число кладётся в самый конец массива, а затем «просеивается» вверх (**Sift Up**), пока его родитель не станет больше него.
3. **Extract (Извлечение максимума):** Максимум всегда лежит в корне — `arr[0]`. Мы запоминаем его, переносим самый последний элемент массива в корень, уменьшаем длину массива на 1 и «просеиваем» этот элемент сверху вниз (**Sift Down**), восстанавливая свойства кучи.

---

## 📥 Формат ввода
* **Первая строка:** количество команд N (1 ≤ N ≤ 100 000).
* **Следующие N строк:** команды. Либо `0 <число>` (вставка), либо `1` (извлечение).

## 📤 Формат вывода
* Для каждой команды `1` (Extract) вывести извлечённое число на отдельной строке.

---

## 💡 Пример
**Входные данные:**
```text
2
0 10000
1
```

**Выходные данные:**
```text
10000
```
