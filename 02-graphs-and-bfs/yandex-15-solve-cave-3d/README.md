# 🕳️ yandex-cave-3d. Путь спелеолога (3D BFS)

## 📝 Условие задачи
Пещера представлена кубом, разбитым на N частей по каждому измерению (то есть на N³ кубических клеток). Каждая клетка может быть или пустой (`.`), или полностью заполненной камнем (`#`). Исходя из начального положения спелеолога (обозначено буквой `S`), требуется найти, какое минимальное количество перемещений по клеткам ему требуется, чтобы выбраться на поверхность. 

Переходить из клетки в клетку можно, только если они обе свободны и имеют общую грань (всего 6 направлений движения). Самый первый блок во входных данных представляет собой верхний уровень пещеры. Достижение **любой свободной клетки на этом самом верхнем уровне (этаж 0)** означает выход на поверхность. Выход на поверхность всегда возможен.

---

## 🎯 Суть алгоритма
Задача решена с помощью **Поиска в ширину в трёхмерном пространстве (3D BFS)**.
1. **Разбор 3D-координат из плоской ленты:** Входные данные считываются сплошной лентой строк. Чтобы перевести плоский индекс строки `i` в честные 3D-координаты, применяется математика:
   * Номер этажа (`L` или `level`): `Math.floor(i / N)` [INDEX]
   * Номер строки внутри этажа (`row`): `i % N` [INDEX]
   * Номер столбца (`col`): находится через `.indexOf('S')` в строке [INDEX]
2. **Карта расстояний:** Создаётся трёхмерная матрица `distance[L][row][col]`, изначально заполненная значениями `-1`. В стартовую ячейку спелеолога `S` принудительно записывается `0`.
3. **6 направлений:** Обход 6 соседей кубика (вверх/вниз по этажам, а также север/юг/запад/восток) реализован компактно через три **массивы смещений** (`dL`, `dR`, `dC`).
4. **Условие победы:** Поиск в ширину работает через очередь (`queue`). Как только первая извлечённая из начала очереди точка оказывается на самом верхнем этаже (`current.L === 0`), алгоритм мгновенно завершается и возвращает накопленное для неё количество шагов [INDEX].

---

## 📥 Формат ввода
* **Первая строка:** целое число N (1 ≤ N ≤ 30) — размер куба пещеры.
* **Далее следуют N блоков**, разделённых пустой строкой. Каждый блок состоит из N строк по N символов (`#` — камень, `.` — пусто, `S` — старт).

## 📤 Формат вывода
* Единственное число — минимальная длина пути до поверхности (количество рёбер/шагов).

---

## 💡 Пример
**Входные данные:**
```text
3

###
###
###

###
#S#
###

###
###
###
```

**Выходные данные:**
```text
1
```
*(Пояснение: спелеологу достаточно сделать ровно 1 шаг вертикально вверх со второго блока на первый, чтобы оказаться на поверхности).*
