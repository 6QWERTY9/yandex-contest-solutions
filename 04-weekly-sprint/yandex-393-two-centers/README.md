# 📈 yandex-393-two-centers Два центра

## 📝 Условие задачи
**Дано взвешенное дерево *T*.**

Назовем 2-радиусом минимальную величину *r*, для которой существуют **2 смежные вершины *u* и *v***, что для любой вершины *w* верно неравенство:

*min(distance(u,w),distance(v,w)) ≤ r*

---

## 🎯 Суть алгоритма

1. **Концепция:** 
    - Построить дерево.
    - Циклом перебрать каждое ребро. Концы этого ребра — это наши центры \(u\) и \(v\).
    - Для каждого ребра моментально узнать самые длинные пути в половинке \(u\) и в половинке \(v\).
    - Выбрать из двух путей максимальный.
    - Среди всех ребер найти минимальный из этих максимумов и вывести его как результат.

---

## 📥 Формат ввода
- **В первой строке:**  записано единственное число *n* - количество вершин в дереве (3 ≤ *n* ≤ 2222)
- **Далее в n−1 строке:** идут описания ребер в формате *a,b,c* (1 ≤ a < b ≤ n 1≤ c ≤ 500 000) - **между вершинами a и b есть ребро длины c**.
---


## 📤 Формат вывода
В единственной строке выведите значение 2-радиуса.
---

## 💡 Пример
**Входные данные:**
```text
3
1 2 5
2 3 10
```

**Выходные данные:**
```text
5
```
