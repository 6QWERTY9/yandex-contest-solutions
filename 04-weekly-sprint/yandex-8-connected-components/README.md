# 📈 yandex-8-connected-components Компоненты связности

## 📝 Условие задачи

**Дан неориентированный невзвешенный граф**, состоящий из *N* вершин и *M* ребер. Не**обходимо посчитать количество его компонент связности и вывести их**.

Компонента связности в неориентированном графе - **это подмножество вершин, таких что все вершины достижимы друг из друга**.
---
## 🎯 Суть алгоритма
1. **Концепция:** Строим наш неориентированный невзвешенный граф, 
2. **заводим наши переменные:** (`countConnection`) - счетчик компонентов связности, (`components`) - вложенный массив где мы будем хранить [[`кол-во вершин`, [`сами вершины`]]]
3. **Расчет DFS:** запускаем DFS 

---

## 📥 Формат ввода
- **В первой строке:** дано два числа *N* и *M* (0 < *N* ≤ 100 000, 0 ≤ *M* 100 000)
- **В следующих *M* строках:** записано по два числа *i* и *m* (1 ≤ *i*,*j* ≤ *N*), которые означают, что вершины *i* и *j* соединены ребром.

## 📤 Формат вывода
В первой строчке выходного файла **выведите количество компонент связности**.

Далее выведите сами компоненты связности в следующем формате: 
  * **в первой строке количество вершин в компоненте.** 
  * **Во второй - сами вершины в произвольном порядке.**
---

## 💡 Пример
**Входные данные:**
```text
6 4
3 1
1 2
5 4
2 3
```

**Выходные данные:**
```text
3
3
1 2 3 
2
4 5 
1
6 
```
