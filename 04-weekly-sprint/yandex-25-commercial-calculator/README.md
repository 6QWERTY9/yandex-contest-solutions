# yandex-25-commercial-calculator

## 📝 Условие задачи

Этот калькулятор **берёт с пользователя деньги за совершаемые арифметические операции**. **Стоимость каждой операции в евро равна 5% от числа, которое является результатом операции**. На этом калькуляторе требуется вычислить сумму N натуральных чисел (числа известны).

Нетрудно заметить, что от того, в каком порядке мы будем складывать эти числа, иногда зависит, в какую сумму денег нам обойдётся вычисление суммы чисел **(тем самым оказывается нарушен классический принцип «от перестановки мест слагаемых сумма не меняется»)**.

---

## 🎯 Суть алгоритма
Задача сводится к последовательному объединению элементов с целью минимизировать промежуточные суммы. Это классическая задача на **жадный алгоритм** (Greedy Algorithm).

1. **Стратегия выбора:** На каждом шаге из кучи извлекаются два минимальных элемента. Их сумма добавляется к общему счетчику стоимости (с учетом 5%) и вставляется обратно в кучу.
2. **Структура данных:** Для эффективного поиска минимумов используется самостоятельно реализованная **Min-Heap (Минимальная куча)** на базе одномерного массива. Это позволяет производить операции извлечения и вставки за $O(\log N)$, что обеспечивает общую сложность алгоритма $O(N \log N)$.

---

## 📥 Формат ввода

* **Первая строка:**  содержит число N (2 ≤ N ≤ 100 000).
* **Во второй строке** заданны N натуральных чисел, каждое из которых не превосходит 10000.

## 📤 Формат вывода
* Определите, сколько денег нам потребуется на нахождения суммы этих N чисел. Результат должен быть выведен с двумя знаками после десятичной точки.

---

## 💡 Пример
**Входные данные:**
```text
4
10 11 12 13
```

**Выходные данные:**
```text
4.60
```
