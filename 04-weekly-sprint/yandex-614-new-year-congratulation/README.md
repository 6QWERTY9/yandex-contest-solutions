# 📈 yandex-614-new-year-congratulation Новогоднее поздравление

## 📝 Условие задачи
~~Кодерун любит дарить подарки и всегда навещает своих друзей перед Новым годом, чтобы успеть их поздравить. Новогодним вечером он решил обойти нескольких друзей и пожелать им хороших праздников.~~

~~В районе, где живут Кодерун и его друзья, все дома расположены на одной прямой.~~

**Дом Кодеруна стоит в точке с координатой 0.** 
**Всего у Кодеруна n друзей.**

Дом каждого друга задаётся на этой прямой своей **координатой x<sub>i</sub>.**

Для того, чтобы перейти из координаты x<sub>i</sub> в координату x<sub>j</sub>, Кодерун тратит **|x<sub>i</sub> - x<sub>j</sub>|**.

~~Добраться до друга — лишь первая сложность, с которой предстоит столкнуться нашему герою.~~

Для каждого друга он прикинул время **t<sub>i</sub> в секундах, за которое Кодерун поздравит его** с праздником.

**Если несколько друзей располагаются в одной точке**, то Кодеруну не нужно перемещаться от одного к другому, **но каждому другу он озвучит поздравление по отдельности** (времена t<sub>i</sub> суммируются).

**До Нового года осталось всего T секунд** и Кодерун хочет хочет поздравить как можно большее количество друзей. Изначально он находится у себя дома, **в точке с координатой 0**.

Помогите Кодеруну вычислить, **какое максимальное количество друзей** он может поздравить с Новым годом за T секунд!


---
## 🎯 Суть алгоритма

1. **Сортировка:** 

Сортируем всех друзей по возрастанию их координат \(x_i\).

2. **Сканирование прямой:** 

Поочередно перебираем друзей. Для каждого текущего друга мы знаем его координату \(x_i\) (время на дорогу в одну сторону) и время поздравления \(t_i\).

3. **Наполнение кучи:** 

Добавляем текущее время разговора \(t_i\) в кучу. Также прибавляем \(t_i\) к переменной `currentTalkTime` (общая сумма времени на поздравления).

4. **Проверка лимита:** 

Проверяем условие: если (время на дорогу \(x_i\) + `currentTalkTime`) превышает доступное время \(T\), значит, мы не успеваем.

5. **Жадное удаление:** 

Пока мы не укладываемся в лимит времени \(T\), мы извлекаем из кучи элемент с максимальным временем разговора. Мы вычитаем его из `currentTalkTime` и тем самым «отменяем» поздравление этого друга, освобождая максимум времени.

6. **Финал:** 

В самом конце, когда мы дойдём до конца массива, ответом будет являться максимальный размер кучи, который удалось зафиксировать в процессе (или размер кучи на финальном шаге).

---

## 📥 Формат ввода
* **В первой строке:** записанны два целых числа n и T (1 ≤ n ≤ 100 000, 1 ≤ T ≤ $10^9$) - **количество друзей и доступное время.**
* **В каждой из следующих n строк:** дано по два целых числа x<sub>i</sub> и t<sub>i</sub> (1 ≤ x<sub>i</sub>, t<sub>i</sub> ≤ $10^9$) - **координата i-го друга и время, за которое Кодерун поздравит i-го друга с праздником.**

## 📤 Формат вывода

**В единственной строке выходного файла выведите максимальное количество друзей, которых Кодерун успеет поздравить за T секунд.**

---

## 💡 Пример
**Входные данные:**
```text
3 10
1 4
2 5
3 3
```

**Выходные данные:**
```text
2
```
