# 📈 yandex-43-two-horses — Два коня

## 📝 Условие задачи
На стандартной шахматной доске **(8х8)** живут 2 шахматных коня: **Красный и Зелёный**. 

Обычно они беззаботно скачут по просторам доски, пощипывая шахматную травку, но сегодня особенный день: у Зелёного коня День Рождения. 

**Зеленый конь решил отпраздновать это событие вместе с Красным**. Но для осуществления этого прекрасного плана **им нужно оказаться на одной клетке.** 

Заметим, что Красный и Зелёный шахматные кони сильно отличаются от черного с белым: **они ходят не по очереди, а одновременно, и если оказываются на одной клетке, никто никого не съедает.**

**Сколько ходов им потребуется, чтобы насладиться праздником?**

---
## 🎯 Суть алгоритма

- **Суть алгоритма:** надо найти наименьшее необходимое количество ходов чтобы два коня встретились

    **1\. Примечание:**
    * **Кони ходят буквой Г в 8 направлениях**
    * **Кони ходят одновременно**
    * **Им нужно оказаться на одной клетке**

> [!NOTE] 
> **Мои мысли:**
>
> Обязательно ли делать ходы двумя конями, или можно использовать второго как цель? Вроде как на бумаге количество ходов не меняется.
>
> ---
> **💡 Вывод:** Надо ходить **одновременно двумя конями**. Хоть количество ходов и не меняется, это влияет на то, смогут ли они оказаться на одной клетке или нет.


- **Разбор алгоритма:** 

    * **Напишем вспомогательную функцию для перевода координат `parseCoordinates`:** функция будет переводить координаты из (`a1`) в (`[1,1]`)
        * Функция будет принимать в качестве входных данных координаты в формате - (`a1`)
        * В функции мы заводим вспомогательную строку в которой будем хранить буквы от a до h. С помощью метода `.indexOf()` будем доставать индексы + 1
        * Разделяем строку на букву и цифру после с помощью `Array.indexOf` достаем индекс столбца объединяем все в список и возвращаем массив в формате `[number,number]`


    * **Заводим массив ходов коня `KNIGHT_MOVES`:** Вспомогательный массив где будут храниться ходы коня 


    * **Поиск в ширину:**
        * **Заводим нашу функцию:** (`BFS`) на вход она будет принимать стартовые координаты двух коней в формате `[number, number]`
        
        * **Заводим следующие переменные:**
            - **`queueFirstKnight` (очередь)** — обычный массив, куда складываются вершины для проверки.
            - **`queueSecondKnight` (очередь)** — обычный массив, куда складываются вершины для проверки.
            - **`headFirstKnight` (указатель)** — индекс текущего элемента в очереди.
            - **`headSecondKnight` (указатель)** — индекс текущего элемента в очереди.
            - **`distFirstKnight` (расстояния)** — двумерный массив 9×9, заполненный `-1`
            - **`distSecondKnight` (расстояния)** — двумерный массив 9×9, заполненный `-1`

        * **Инициализация:**
            - **Кладем стартовые координаты коней в свои очереди `queue`**
            - **Отмечаем стартовые позиции значением 0 в массивы расстояния `dist`**

        * **Запускаем два отдельных цикла while (по одному на каждого коня, чтобы не смешивать их очереди):**
            - **Пока указатель head меньше длины своей очереди `queue`:**
	            - **Достаём текущую клетку из очереди и сдвигаем указатель `head` на +1.**

            * **Запускаем вложенный цикл `for ... of` по ходам коня из нашего списка `KNIGHT_MOVES`:** 
            - **Рассчитываем следующие координаты хода коня:**
                - **`const nextR = r + dr;`**
                - **`const nextC = c + dc;`**

            - **Проверяем границы доски:**
                - **`nextR >= 1 && nextR <= 8 && nextC >= 1 && nextC <= 8`**

                - **Проверяем, были ли мы уже на этой клетке:** если в матрице `dist` для новой клетки всё ещё стоит -1:
	                - **Записываем расстояние:** берём расстояние до текущей клетки и прибавляем 1.
	                - **Кладём новую клетку в очередь `queue`,** чтобы позже проверить ходы уже из неё.
        
        * **Поиск минимального количества ходов:**
            - **Заводим переменную для ответа `res = Infinity`**

            - **Бежим вложенными циклами по всем клеткам доски:**
                - **Для каждой клетки проверяем два условия:**
                    - **Оба коня могут до неё добраться:** значения в `distFirstKnight` и `distSecondKnight` не равны `-1`.
                    - **Совпадает чётность ходов:** **остаток от деления на 2 у обоих расстояний одинаковый**

                - **Если оба условия выполнены:**
                    - Если оба условия подходят, смотрим, кто из коней доберётся до этой клетки дольше (берём большее из двух расстояний через Math.max) и кладем его в переменную `moves`
                    - Сравниваем его с текущим ответом `res > moves` и сохраняем меньшее значение `res = moves`. 

            - **После проверки всей доски возвращаем найденный ответ, а если подходящих клеток не нашлось возвращаем -1.**

## 📥 Формат ввода
- **На вход программы поступают координаты коней** - записанные по стандартным **шахматным правилам** (т.е. двумя символами - маленькая латинская буква (от a до h) и цифра (от 1 до 8), задающие столбец и строку соответственно).

## 📤 Формат вывода
**Требуется вывести наименьшее необходимое количество ходов, либо число -1, если кони не могут встретиться.**
