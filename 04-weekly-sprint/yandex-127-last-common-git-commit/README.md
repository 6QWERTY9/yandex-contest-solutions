# 📈 yandex-127-last-common-git-commit Последний общий коммит веток git.

## 📝 Условие задачи
Необходимо написать функцию, **которая на вход получает информацию о коммитах и массив из двух имён веток, а на выход отдаёт сообщение их последнего общего коммита**.

### Структура коммита:
    ```js
        // ? - необязательные поля (могут отсутствовать в объекте)
        interface Commit {
            id: string; // уникальный идентификатор коммита
            timestamp: number; // время создания в миллисекундах
            parents?: string[]; // массив id родительских коммитов
            message?: string; // сообщение коммита
            branches?: string[]; // массив имён веток
        }
    ```

    **Все коммиты имеют уникальные id, все id родительских коммитов соответствуют коммитам в массиве.** 
    В целом, считаем, что входные данные корректны и дополнительная их проверка не требуется.


---
## 🎯 Суть алгоритма

1. **Концепция:**
    * **Если общих коммитов больше одного**:
        1. Сначало мы для каждой из двух веток собираем множество `id` всех коммитов этих веток.
            1. Ищем коммиты у которых в `branches` есть имя ветки, и дальше идем по родителям вглубь пока не кончатся родители
            2. Нашли нужную ветку добавили `id` в множество этой ветки.
        
        2. После того как мы заполнили два множества:
            1. ищем их пересечение.
            2. Берем `id` из пересечение и сравниваем их по времени `timestamp`
            3. выводим сообщение того коммита у которого  `timestamp` больше
                * При **отсутствии поля message** у коммита вернуть пустую строку ''

            4. если пересечений нет то:
                * выбросить ошибку c message **'No common commit'**
    * **При отсутствии общего коммита или если объекта `commits` нет вовсе:**
        * выбросить ошибку c message **'No common commit'**

---

## 📥 Формат ввода
```js
getLastCommonCommitMessage([
    {
    id: '1',
    message: 'initial commit',
    timestamp: 1624010073113, // -> время меньше чем у id - 2
    },
    {
    id: '2',
    parents: ['1'],
    message: 'add layout', // -> ответ - add layout
    timestamp: 1624010082219, // -> время больше чем у родителя
    },
    {
    id: '3',
    parents: ['2'], // -> родитель коммит с айди 2
    message: 'fix bugs',
    timestamp: 1624010109039, 
    branches: ['master', 'bugfix'] // -> ветка из нашего списка bugfix
    },
    {
    id: '4',
    parents: ['2'], // -> родитель коммит с айди 2
    message: 'add link',
    timestamp: 1624010179662,  
    branches: ['feature/link'] // -> ветка из нашего списка feature/link
    }
], ['bugfix', 'feature/link']) // 'add layout'

```

## 📤 Формат вывода
**отдаёт сообщение их последнего общего коммита**
---
## Примечание
* **Найденный коммит должен быть последним по времени (если общих коммитов больше одного)**, то есть самым поздним. **У всех коммитов гарантированно разное время**;
* Массив id для родительских коммитов **не упорядочен по времени их создания;**
* **При отсутствии поля message у коммита вернуть пустую строку '';**
* При отсутствии общего коммита выбросить ошибку c message **'No common commit'**;*
