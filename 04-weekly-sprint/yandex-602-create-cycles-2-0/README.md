# 📈 yandex-602-create-cycles-2-0 Создать циклы

## 📝 Условие задачи
Вам дана схема метро, **состоящая из n и m** **двусторонних туннелей между парами станций**. 

Гарантируется, что по заданным туннелям можно добраться **от любой станции до любой другой**. 

Кольцевой веткой называется **последовательность различных туннелей, по которой можно проехать от станции до нее самой же с посещением других станций, не оказываясь на одной и той же станции дважды.**

Вы хотите построить теперь некоторое количество туннелей между станциями, чтобы появилось **ровно столько же новых кольцевых веток, сколько вы построили туннелей.** 

**Вы можете строить новый туннель между станциями, которые были соединены ранее.** 

**Вы не можете добавлять новый туннель из какой-то станции в неё же.** 

- **При этом, появляется дополнительное условие:** вы хотите, чтобы в итоговой схеме метро каждый туннель **принадлежал хотя бы одной кольцевой ветке(необязательно новой).** 

**Посчитайте количество способов построить новые туннели. Так как ответ может быть большим, выведите его по модулю 998244353.**


--- 
## 🎯 Суть алгоритма

Чтобы решить задачу, разделим все туннели на две группы: те, что уже входят в старые кольца, и одиночные туннели без объездов (**мосты**).

1. **Старые кольца — это барьеры:** 
   Новый туннель нельзя проводить так, чтобы путь между его концами проходил через старое кольцо. Иначе кольцо можно будет объехать двумя способами, и вместо одного нового цикла появится сразу два или больше. Поэтому старые кольца просто делят схему метро на независимые части, состоящие только из мостов (деревья).

2. **Разбиение мостов на дорожки:** 
   Чтобы каждый мост вошёл хотя бы в одно кольцо, а лишние циклы не возникали, все мосты нужно разбить на простые пути без общих рёбер. Концы каждого такого пути мы соединяем одним новым туннелем.

3. **Подсчёт комбинаций на каждой станции:** 
   На каждой станции сходящиеся в ней мосты ($k$ штук) можно либо соединять в пары (продолжая путь через станцию), либо оставлять без пары (заканчивая путь на этой станции). 
   Количество способов разбить $k$ мостов на пары и одиночки считается динамически (числа телефонных соединений / инволюций):
   * `ways[0] = 1`
   * `ways[1] = 1`
   * `ways[k] = ways[k - 1] + (k - 1) * ways[k - 2]`

4. **Итоговый ответ:** 
   Выбор на каждой станции не зависит от других станций. Поэтому достаточно найти все мосты (например, поиском в глубину — DFS), посчитать степень $k$ (количество примыкающих мостов) для каждой вершины и перемножить значения `ways[k]` для всех вершин по модулю $998244353$.

---

## 📥 Формат ввода

- **В первой строке вводятся:** два числа $2 \le n \le 10^5, 1 \le m \le \min\left(10^5, \frac{n \cdot (n-1)}{2}\right)$

- **В следующих $m$ строках вводится** пара чисел $u_i, v_i$ ($1 \le u_i, v_i \le n$) — **номера станций, которые соединяет $i$-й туннель.**

Гарантируется, что никакой туннель **не соединяет станцию саму с собой и для каждой пары станций есть не более чем один туннель, их соединяющий.**
