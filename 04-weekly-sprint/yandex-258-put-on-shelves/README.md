# 📈 yandex-241-bypass Обход

## 📝 Условие задачи
Маша работает мерчендайзером в компании АльМека. Завтра у неё экзамен после переподготовки и она к нему готовится в последний день. В голове у Маши всё перемешалось. **Помнит она то ли про товары, то ли про отзывы на товары.** **Нужно помочь ей расставить всё по местам и сериализовать итоговый результат в текстовый документ.**

Известно, что есть 2 типа данных: **good и comment**.

```js
class Good {
    name: string;
    comments: Comment[];
    related: Good[];
};

class Comment {
    text: string;
    comments: Comment[];
    parent: Good | Comment;
};
```


---
## 🎯 Суть алгоритма
1. **Концепция:**
    - Задача в том, чтобы, начав с этой ссылки, собрать вообще всё: товары, их отзывы, ответы на отзывы и похожие товары, а потом оформить это в Markdown ровно в том виде, что в примере — два раздела, отзывы с указанием товара и списком ответов, товары со списком похожих, всё по алфавиту.

2. **Создание неориентрованного графа:**
    - создаем переменную `graph = {}`
    - заполняем вершины пустыми массивами `graph[vertex] = []`
    - заполняем связи прямую - `graph[from] = to` и обратную - `graph[to] = from`
    - возвращаем наш `graph`

3. **Обход DFS:** 
    - создаем коллекцию посещенний чтобы там хранились только уникальные значения `visited = new Set()`
    - Логика обхода: 
        * Если `dfs` находится в товаре то он должен попытатся пойти во все связанные товары - `related` и во все его комментарии `comments`
        * Если `dfs` находится в комментарии то он должен попытатся пойти вверх к родителю `parent` и вниз ко всем ответам `comments`
    - После обхода у нас будет коллекция у вас будет коллекция, содержащая каждый товар и каждый комментарий ровно в одном экземпляре.

4. **Фильтрация и группировка:**
    Нужно нашу коллекцию разделить на две группы: 
    - **Товары:** Просто отбираем все объекты с типом `good`
    - **Корневые отзывы:** Нам нужны только те комментарии, которые привязаны **напрямую к товару.**
    То есть мы отбираем объекты с типом `comment`, у которых поле parent указывает на объект с типом `good`

5. **Сортировка и генерация Markdown:**
    Напишем единную функцию которая будет сортировать и генировать строки под `Markdown`

    - **Отзывы:** 
        * Берем список корневых отзывов и сортируем их по алфавиту
        * Для каждого корневого отзыва формируем строку: `%(comment)% - про %(parent.name)%`
        * Чтобы вывести вложенные комментарии напишем рекурсивную функцию:
            - Она принимает текущий комментарий и текущий уровень вложенности (глубину).
            - Перед печатью детей она обязательно сортирует массив comments этого узла по алфавиту.
            - Для каждого ребенка она делает отступ (например, глубина умножить на 4 пробела), ставит дефис -, выводит текст ответа и рекурсивно вызывает сама себя для его детей, увеличивая глубину на 1.

    - **Товары:**
        - Берем список товаров и сортируем его по алфавиту (по названию name).
        - Для каждого товара формируем строку - %Название товара%.
        - Берем его массив related, сортируем его по алфавиту (по названию связанных товаров).
        - Для каждого связанного товара формируем строку с отступом в 4 пробела, но маркер меняем на звёздочку: * %Название похожего товара%.

6. **Финал:**

В самом конце вы склеиваете заголовок ## Отзывы, строки отзывов, пустую строку, 
заголовок ## Товары и строки товаров. Результат возвращается в виде одной большой строки Markdown.

## 📥 Формат ввода
Ссылка на JS-объект

## 📤 Формат вывода
Строка в формате Markdown со всеми найденными данными

Markdown-документ должен иметь следующий формат:

```md
## Отзывы

- %Отзыв 1% - про %Товар 1%
  - %Ответ на отзыв 1%
  - %Ответ на отзыв 2%
    - %Ответ на ответ к отзыву 1%
  - %Ответ на отзыв 3%
- %Отзыв 2% - про %Товар 2%
- %Отзыв 3% - про %Товар 3%
  - %Ответ на отзыв 4%
  - %Ответ на отзыв 5%

## Товары

- %Товар 1%
  * %Товар 2%
- %Товар 3%
  * %Товар 2%
  * %Товар 4%
```

## 💡 Пример
**Входные данные:**
```js
// Товары в памяти
const Good1 = { type: 'good', name: 'Смесь Friso Frisolaс Gold 2035', comments: [], related: [] };
const Good2 = { type: 'good', name: 'МакБук PRO 2035 13\' w/ clickbar', comments: [], related: [] };
const Good3 = { type: 'good', name: 'Фигурка Funko POP! Vinyl: Overwatch Уинстон', comments: [], related: [] };

// Отзывы в памяти
const Comment1 = { type: 'comment', text: 'Классный ноутбук!', comments: [], parent: null };
const Comment2 = { type: 'comment', text: 'Не понравился! Кликбар не работает совсем!', comments: [], parent: null };
const Comment3 = { type: 'comment', text: 'Хорошая цена, у малыша не было аллергии на неё', comments: [], parent: null };

// Похожие товары
Good3.related.push(Good1, Good2)
Good1.related.push(Good3)
Good2.related.push(Good3)

// Расставляем комментарии
Comment1.parent = Good2;
Good2.comments.push(Comment1);

Comment2.parent = Comment1;
Comment1.comments.push(Comment2);

Comment3.parent = Good1;
Good1.comments.push(Comment3);

// А ссылка осталась только на третий отзыв :-(
module.exports = Comment3;
```
