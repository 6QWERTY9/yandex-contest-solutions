# 📈 yandex-45-toy-maze Игрушечный лабиринт

## 📝 Условие задачи
Игрушечный лабиринт представляет собой прозрачную плоскую прямоугольную коробку, внутри которой есть препятствия и перемещается шарик. 

Лабиринт можно наклонять влево, вправо, к себе или от себя, после каждого наклона шарик перемещается в заданном направлении до ближайшего препятствия или до стенки лабиринта, после чего останавливается. 

Целью игры является загнать шарик в одно из специальных отверстий – **выходов**. Шарик проваливается в отверстие, если оно встречается на его пути (шарик не обязан останавливаться в отверстии).

Первоначально шарик находится в левом верхнем углу лабиринта. Гарантируется, **что решение существует и левый верхний угол не занят препятствием или отверстием.**

---
## 🎯 Суть алгоритма

- **Суть алгоритма:** Поиск кратчайшего пути в матрице(лабиринте)

    * **Число 0 - свободное место**
    * **Число 1 - препятствие**
    * **Число 2 - выход**

    * Ход шарика - **шарик двигается до первого препятсвия или до границы лабиринта**

- **Разбор алгоритма:** 
    * **Заводим вспомогательный массив направлений `DIRECTIONS_4`**

    * **Создаем функцию `findShortestPath`:** она будет принимать следующие аргументы
        * `sizes` - размеры матрицы в виде массива чисел `[n, m]`
        * `matrix` - саму матрицу лабиринта 

    * **Заводим следующие переменные:** 
        * **`queue` (очередь)** — обычный массив
        * **`head` (указатель)** — индекс текущего элемента в очереди.
        * **`dist` (расстояния)** — массив размером n на m, заполненный `-1`.

    - **Инициализация:** 
        * **Кладем начальные координаты `[0, 0]` в нашу `queue` (очередь)**
        * **Отмечаем стартовую позицию - `dist[0][0] = 0`**

    - **Запускаем цикл while пока `head < queue.length`:**
        * **Достаем текущие координаты `[row, col]` из очереди `queue`**
        * **Двигаем указатель `head` на 1**

        * **Проходим циклом `for` по 4 направлениям из `DIRECTIONS_4`:**
            * Ставим временные координаты `currRow = row`, `currCol = col`
            * **Запускаем внутренний цикл `while`:**
                * Проверяем, что следующий шаг (`currRow + dr`, `currCol + dc`) находится **внутри границ** (`>= 0` и `< n / m`) и **там не стена** (`!== 1`)
                * Если условие выполнено — сдвигаем `currRow` и `currCol` на этот шаг
                * **Точка выхода (на лету):** если в новой клетке лежит отверстие (`matrix[currRow][currCol] === 2`), сразу возвращаем ответ `dist[row][col] + 1`

            * **Фиксируем точку остановки (после внутреннего `while`):**
                * Проверяем, были ли мы в этой клетке раньше: `dist[currRow][currCol] === -1`
                * Если не были — записываем расстояние `dist[currRow][currCol] = dist[row][col] + 1`
                * Кладём координаты остановки `[currRow, currCol]` в конец очереди `queue`

## 📥 Формат ввода
- **В первой строке входного файла:** записаны числа N и M – размеры лабиринта (целые положительные числа, не превышающие 100)

- **Затем идет N строк по M чисел в каждой:** описание лабиринта. **Число 0 в описании означает свободное место**, **число 1 – препятствие**, **число 2 – отверстие.**

## 📤 Формат вывода
Выведите единственное число – минимальное количество наклонов, которые необходимо сделать, чтобы шарик покинул лабиринт через одно из отверстий.
---

## 💡 Пример
**Входные данные:**
```text
4 5
0 0 0 0 1
0 1 1 0 2
0 2 1 0 0
0 0 1 0 0
```

**Выходные данные:**
```text
3
```
